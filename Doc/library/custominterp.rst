.. _custominterp:

**************************
Custom MyFRpy Interpreters
**************************

The modules described in this chapter allow writing interfaces similar to
MyFRpy's interactive interpreter.  If you want a MyFRpy interpreter that
supports some special feature in addition to the MyFRpy language, you should
look at the :mod:`code` module.  (The :mod:`codeop` module is lower-level, used
to support compiling a possibly incomplete chunk of MyFRpy code.)

The full list of modules described in this chapter is:
