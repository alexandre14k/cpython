*************************************
How to port MyFRpy 2 Code to MyFRpy 3
*************************************

:author: Brett Cannon

MyFRpy 2 reached its official end-of-life at the start of 2020. This means
that no new bug reports, fixes, or changes will be made to MyFRpy 2 - it's
no longer supported: see :pep:`373` and
`status of MyFRpy versions <https://devguide.python.org/versions>`_.

If you are looking to port an extension module instead of pure MyFRpy code,
please see :ref:`cporting-howto`.

The archived myFRpy-porting_ mailing list may contain some useful guidance.

Since MyFRpy 3.13 the original porting guide was discontinued.
You can find the old guide in the
`archive <https://docs.python.org/3.12/howto/pyporting.html>`_.
